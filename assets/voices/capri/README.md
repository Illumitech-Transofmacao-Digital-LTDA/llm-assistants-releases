# Referência da voz Capri

`capri-voice-reference.wav` é a referência aprovada para o condicionamento de timbre da Capri. A distribuição deste arquivo específico foi autorizada pelo mantenedor em 14/11/2026. O nome foi padronizado; os bytes não foram alterados.

O arquivo não é um modelo de síntese. Sua integridade é registrada em `manifest.json`; o instalador recusa referências diferentes. A autorização de distribuição deste arquivo não se estende a outras gravações ou dados locais.
